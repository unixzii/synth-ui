# @synth-ui/widgets

The theme, icons and controls of [synth-ui](https://github.com/unixzii/synth-ui),
an immediate-mode pixel UI library: buttons, knobs, sliders, text fields,
lists, menus, sheets and more, drawn through `@synth-ui/core`.

```bash
npm install @synth-ui/core @synth-ui/widgets @synth-ui/backend
```

See the [repository's README](https://github.com/unixzii/synth-ui#readme)
for how to use it.
