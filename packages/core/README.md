# @synth-ui/core

The foundation of [synth-ui](https://github.com/unixzii/synth-ui), an
immediate-mode pixel UI library: regions, layout, input, state, animation
and palettes. It has no platform dependency; `@synth-ui/backend` puts it on
a web page.

```bash
npm install @synth-ui/core @synth-ui/widgets @synth-ui/backend
```

See the [repository's README](https://github.com/unixzii/synth-ui#readme)
for how to use it.
